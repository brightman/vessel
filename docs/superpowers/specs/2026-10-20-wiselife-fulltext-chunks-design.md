# WiseLife 第二阶段：全文检索与完整分段索引

用户已同意数据架构演进顺序，并在第一阶段交付后明确要求继续。本阶段落实既有第二优先项，不重复请求实施许可。

## 目标与选择

让中文关键词、长录音结尾、图片 OCR 和其他原文都可在本机检索。保留当前按单日查看/问答以及 AI 来源权限。大媒体、业务主表、ASR/生成模型配置均保持现状。

方案比较：纯 SQL 子串匹配准确但长文本扫描成本高；自建中文倒排表维护成本较高；采用系统 SQLite FTS5 trigram，配合短词 SQL 子串查询，可利用现有依赖并覆盖中文。选择第三种。已用本机 SQLite 内存库验证连续中文 trigram 与双字 SQL 子串命中。若运行平台不支持 trigram，使用有日期/类型范围的 SQL 子串检索，并标明降级。

## 全文索引

- 使用共享 DaybookDatabase 新增独立可重建领域，保存传入 DayRecord 的完整标题、原文、总结、UUID、日期、类型及内容指纹。同步只修改变化的行，删除不再存在的行；派生数据不能改写业务原文。
- 文本归一化规则固定且版本化，查询用同一规则；所有用户文本绑定参数，FTS 操作符/引号只按字面文本处理。短中文、标点、混合语言、大小写、组合 Unicode 不应造成丢结果或 SQL/FTS 注入。
- 普通资料库关键词可检索所有本地记录，包括未允许 AI 读取的来源和生成总结。问 AI 的关键词只查询允许来源的标题/原文，生成总结不参与事实召回；向量也只嵌入允许的原文。
- 日期、来源类型、AI 来源权限在 SQL 候选查询阶段约束。资料列表现有视觉筛选可继续应用到最终显示结果。词项权重与原文摘录保留既有行为，排序稳定；关键词召回与向量召回组合后按记录 UUID 去重。
- 正常索引可用时，资料库与问 AI 真正消费 SQL 关键词结果。数据库不可用或索引更新失败时保留现有内存关键词回退，不能把失败当成空结果。资源未下载不影响 SQL 全文检索。
- 结果必须绑定查询、日期、来源权限和当前内容；普通资料的完整来源快照与 AI 来源快照分别校验，防止未授权来源编辑后复用过期关键词结果。

## 完整分段向量

- 移除前 1,800 字与每条三段的永久覆盖上限。以原文句子边界为优先切分，每段最多 600 个 Swift Character，相邻段最多 80 字重叠；超长句仍切开。保留稳定顺序与字符范围，拼接覆盖完整原文且无空洞。时间戳和说话人检索属于后续阶段，不伪造时间关联。
- 持久化分段计划、内容指纹、模型空间、已完成及不可用状态。每次搜索至多生成 64 个新分段向量，完成的分段不重复生成。重启/下一次搜索从未完成部分继续；不同记录之间轮转处理，单条失败不能使其他记录永久饥饿。
- 资料库搜索处于前台且查询有效时，在批次间让出执行权并继续下一批，展示完成段数/总段数及资源不可用情况。退出、换查询/日期、来源变化、权限撤销、清空或取消立即使旧任务失效；不会后台无期限运行。问 AI 可使用当前批次的结果和完整关键词结果，并如实标注部分向量覆盖。
- 模型标识、修订、维度、语言、pooling 共同区分向量空间；旧空间不能混查。向量不可用的内容记录为未覆盖，并可在资源变化/重建后重试。取消、失败、清空后迟到写入不能恢复旧索引。
- 不再用固定 1,365 条/4,095 段淘汰导致完整索引永远缺失。SQLite 保存完整派生索引；向量候选先按 SQL 范围过滤，再以至多 4,095 行一批执行真实 SQLite Vector 精确扫描，按实际距离合并全范围最优记录。内存随批次有界，扫描不截断尾部。
- Apple 上下文模型可能有自身窗口限制，分段已处理完成不等于模型理解了全部 token；保留这一覆盖说明，不宣称跨语言或真机检索质量已经验证。

## 迁移与安全边界

- 现有 semantic-index-v1 是可重建缓存，可通过一次事务升级/清除为新版本，保留元数据主表和其他领域。清空索引只操作派生表。
- 更新、删记录、撤销 AI 权限、换模型后的行为与现有 generation gate 保持一致；SQL 与 FTS 行、分段计划与进度的提交必须原子一致。
- 保持 SQLite complete 文件保护。错误不删除原始媒体或元数据，不访问实际用户数据库、录音、照片、API Key 或生产服务。
- Ring 仍关闭；不重新生成 App 工程，若添加编译源文件只精确添加 Xcode 引用并维护测试编译列表。

## 验收

真实临时 SQLite + 真实 SQLite Vector 测试：中文 1/2/3+ 字、标点/引号/FTS 操作符、英文大小写/Unicode、全文尾部、摘要仅用于资料库、跨日/来源权限隔离、变更与删除、失败回滚及回退；长文本跨多批/重开恢复、稳定顺序与完整覆盖、失败记录不阻塞其他记录、旧缓存迁移、模型切换、取消/清空后迟到拒绝；超过单次扫描批量的末尾候选能进入最终结果。验证资料库自动续建且取消/资源不足不自旋。

完整本地测试和 iPhone + 内嵌 Watch 模拟器构建通过。真机中文语义质量、功耗与大规模耗时仍需实测。昨日回顾与跨日记忆为第三阶段。
