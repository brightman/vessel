# Huawei WristNotes implementation plan

**Goal:** GT 6 本机录音，近端传输到独立 iPhone App，端上转写和总结。

**Architecture:** Lite Wearable JS 核心 + 经确认的录音/Wear Engine 适配；SwiftUI 本地笔记 App。原 Apple 版保持独立。

## 执行任务

- [x] 记录用户确认的 GT 6 / HarmonyOS 6.1.0；核对系统录音机固件条件及其手机同步限制，整理第三方接入问题。
- [x] 迁移按压状态机到纯 JS；验证轻点、长按松手、取消、短录音和录音中长按。
- [x] 实现串行发送队列与应用级确认状态；验证断线重试、迟到确认、未知 ID、重复确认和删除规则。
- [x] 建立独立 iPhone 工程：拷贝本地笔记/音频/ASR/摘要实现，移除 WatchConnectivity，显示真实未接入状态。
- [x] 加入 Huawei 文件接收边界：校验元数据及实际音频后持久化，并返回确认；用本地真实文件验证重复传输和失败不确认。
- [x] 编译 iPhone、运行逻辑检查、记录实际完成项和外部阻塞项。
- [ ] 获得 GT 6 第三方录音 API 与华为 SDK 后，补齐手表原生界面、录音及设备传输；执行真实 10 秒闭环。
- [ ] 验证长录音、熄屏、中断、断线恢复和首次权限。

最后两项依赖真实华为开发环境和当前未确认的录音接口，不能用模拟成功替代。

2026-10-19：系统主版本已确认，外部阻塞仍为第三方录音接口和 Wear Engine SDK/接入配置。系统录音机要求的更高构建号不是第三方接口可用性的证明。具体问题见 [接入咨询草稿](huawei-integration-inquiry.md)。
