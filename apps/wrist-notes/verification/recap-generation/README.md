# 每日回顾按钮反馈修复

2026-10-28，版本 1.0.1（8）。

## 原因与修复

首页当天默认展示昨日回顾。所选日期没有已允许的记录、录音文字尚未就绪或仍在录音时，原来的 `canGenerate` 会禁用按钮；自定义按钮样式未读取 `isEnabled`，禁用后仍呈现正常颜色。手动生成和外部 AI 确认入口也存在直接返回而无反馈的路径。

- 明确区分加载、后台、录音、无允许数据源、所选日无记录、等待转写和存储异常，并显示不能生成的原因。
- 按钮样式响应禁用状态；历史日期没有可用证据时提供“查看今天的回顾”，打开今天的完整日期范围。
- 手动操作由 model 统一判断可用状态、模型配置与发送确认；条件变化时显示原因，继续保留外部发送确认和资料变更校验。
- 本次未改 Watch 文件传输、握手、保存回执或重试实现，也没有替用户开启任何 AI 数据权限。

## 验证

- `sh scripts/test_daily_recaps.sh` 通过：空日期反馈、切换到今天、文字未就绪、录音中、后台、数据权限、存储失败、发送确认、资料变更和已有回归。
- 独立模拟器副本的三个 XCUITest 通过：空日期 → 查看今天 → 点击生成 → 展示回顾；等待转写时按钮禁用并说明原因；本地 AI 不可用时展示错误。
- UI 测试使用内存数据库和合成文字，生成器为本地测试替身，没有发送真实记录或访问外部 AI。
- Debug 模拟器与 Release 真机架构构建通过，工程版本配置校验通过。截图位于 `build/recap-generation-20261028/`，临时 UI 测试结果位于 `/private/tmp/wiselife-recap-ui-tests.xcresult`。
