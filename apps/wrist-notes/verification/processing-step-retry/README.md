# 完整录音 AI 步骤独立重试

2026-10-29，版本 1.0.1（9）。

## 行为

- 完整录音和旧版长录音的“处理进度”中，“主题拆分与分类”“标题与摘要”失败时各自显示“重新处理”。
- 主题重试仅继续主题拆分与分类，复用现有转写和 Content V2 检查点；不会重新执行 ASR、VAD 或说话人分析。主题完成后，尚未开始的字段任务可点“继续处理”。
- 标题与摘要重试只补齐已定稿片段的缺失字段，保留已完成标题、摘要、人工标题与片段边界。
- 两项分别保存运行状态，字段失败不会把已完成主题误标为失败；重试一项不清除另一项的失败。任务排队、运行、准备确认或正在录音时禁用重复操作。
- 外部 AI 继续使用原有发送确认。授权快照增加步骤标识，单项授权不能用于另一项或完整流程；模型或资料更新后原授权失效。
- 未修改 Watch 传输、同步协议和语音转写任务实现。

## 验证

- `sh scripts/test_content_authorization.sh`：单项与完整授权隔离、预览、资料变化失效、生成字段不使多片段重试中途失去授权。
- `sh scripts/test_content_enrichment.sh`：步骤失败隔离、单项重试状态、补齐缺失字段、保留标题和片段边界、不新增 ASR 推理、不调用主题或分类，以及已有长文本、断点续跑、过期结果和模型不可用回归。
- 三项模拟器 XCUITest：重试字段保留主题失败、重试主题保留字段失败、成功步骤不显示失败重试按钮。UI 使用生产进度行组件及合成状态；生成完成由测试替身模拟，不代表真实长录音模型推理已验收。
- Release 真机架构编译与版本配置校验通过；截图位于 `build/stage-retry-20261029/`，UI 测试结果位于 `/private/tmp/wiselife-stage-retry-ui-tests.xcresult`。
