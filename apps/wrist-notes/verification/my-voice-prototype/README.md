# “我的声音”原型验证 · 2026-10-20

入口：[iPhone 最新原型](../../prototype/iphone-day.html) → 设置 → 语音与 AI → 我的声音。

## 已验证

使用本地 Playwright Chromium，检查真实 DOM 交互；虚拟时钟用于验证时间边界。

- 入口位于语音转写模型与 AI 模型之间，初始为未登记。
- 29 秒不能结束，30 秒可结束，60 秒自动停止并进入确认页。
- 确认只有本人讲话后可保存，取消勾选重新禁用保存；保存后设置摘要与详情更新。
- 重新录制时，取消或按 Escape 保留旧登记；定时器停止，焦点回到设置入口。
- 新登记保存后替换原登记；删除确认可取消，确认删除恢复未登记。
- 原型快进控制可达 30 秒和 60 秒；原有 ASR / AI 模型设置仍可打开。
- 浅色、深色、中英日语言切换，以及 390px / 320px 窄屏无弹层横向溢出。
- 修复缩放后手机容器部分移出视口导致弹层关闭按钮不可见的问题：弹层定位限制在视口内。复现流程修复后通过。
- 刷新清除演示登记；浏览器 JavaScript 错误为 0。`node --check` 与 `git diff --check` 通过。

汇总：[checks.json](checks.json)。截图包含设置入口、准备、录制、确认、已登记、深色和窄屏状态。
