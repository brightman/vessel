# Final 内容片段的时间轴展示与合并设计

状态：待用户审阅；本文件是实现规格，尚未修改应用代码。

## 目标

让首页时间轴只展示已经完成边界确认、并被判定为有意义的内容片段。标题和总结不再阻塞片段展示，可以稍后生成。详情页不提供相邻片段合并入口，但保留对当前片段手动生成标题和总结的能力。时间轴的片段多选合并是唯一的片段合并入口。

## 展示规则

时间轴可见条件为：

```text
segment.isFinal == true
&& segment.hasText == true
&& segment.editorial?.classification == "meaningful"
```

标题和总结为空不影响可见性。生成完成后刷新同一条时间轴记录，不新建重复条目；生成中用轻量占位文案表示状态，不用占位标题或总结伪装成模型结果。

`isFinal` 只表示片段所覆盖的音频范围具有足够的成功 ASR 与 VAD 证据，边界可确定。它不表示分类、标题或总结已经完成。缺少分类、分类为 `lowInformation` 或 `pendingConfirmation`、`isFinal == false`、无转写文本的片段都不出现在时间轴，但保留在完整录音/片段管理数据中，可从来源录音继续查看和处理。

## 处理顺序与数据流

1. 现有 ASR/VAD 处理只将双阶段成功覆盖作为确定边界的证据；待处理、失败或覆盖不足的范围继续保持非 final。
2. 完成该来源当前批次的静音分章、主题切分/相邻边界整理后，边界修订稳定。`isFinal` 仍只表达音频覆盖与边界证据；来源或范围变化会使旧分类失效。
3. 为每个 final、有文本的片段执行独立的内容分类。分类结果写入持久化 `editorial`，并带上模型/引擎版本、证据块 ID 和输入内容签名。只有当前来源修订、片段修订和内容签名仍匹配时才接受结果，避免旧请求覆盖新转写。
4. 分类完成且为 `meaningful` 时立即发布到时间轴，不等待标题或总结。
5. 标题与总结作为后续整理阶段异步生成。失败、取消、模型不可用或等待远程 AI 确认，不撤回已经通过分类的时间轴片段；按现有隐私确认规则执行远程请求。

分类使用既有类别：`meaningful`、`lowInformation`、`pendingConfirmation`。内容分类必须依据片段自身全文，不能从同日其他片段或整条录音推断。当前 V2 分类逻辑只在模拟器试验路径，生产时间轴尚未落库分类；接入生产流水线并持久化分类是实现的前置工作。

## 处理状态

片段详情的“处理状态”应区分并如实显示：转写/VAD 覆盖、边界状态、分类状态、标题状态、总结状态。至少需要覆盖等待、处理中、完成、失败/可重试、模型不可用、等待远程发送确认和内容已更新等状态。没有可靠进度时显示阶段和状态，不显示估算百分比。

来源级处理目前按来源串行；单个来源的标题与总结也按片段顺序整理。实现可先沿用现有调度器，但分类必须先于标题/总结发布，并与二者分开持久化，这样不会因后续生成慢而延迟时间轴展示。

## 手动生成

详情页提供针对当前片段的“生成/重新生成标题”和“生成/重新生成总结”操作，输入仅使用该片段的转写证据，沿用当前 AI 模型设置、远程发送确认、输入签名及防陈旧写入规则。单独重生成一个字段不得重置 `isFinal` 或分类，也不得创建新片段。

当前实现只有来源级“整理主题与总结”按钮，它会遍历该来源的多个含文本片段；没有针对当前片段分别生成标题和总结的按钮。规格要求在详情页补上片段级操作。若来源级按钮继续保留，它仍作为来源级批量处理/重试入口，不替代片段级操作。

## 合并入口与语义

- 删除片段详情“管理片段”菜单中的“与相邻片段合并”；保留拆分、撤销和删除。
- 首页时间轴通过右划、选择、合并来合并内容片段。选中集合必须属于同一来源，并且在完整来源片段序列中连续；不能因为低信息片段被时间轴隐藏，就把其两侧片段误认为相邻。操作调用 `ContentSegmentRepository.merge(ids:expectedRevisions:)`，保留原始音频来源与范围，合并成功后以一个新片段替代被合并片段，再基于合并后的全文生成分类、标题和总结。
- 现有长录音条目的时间轴合并仍是另一种操作：它拼接独立录音文件并生成新的录音记录。多选时不可混合长录音和内容片段；两类记录继续使用各自的数据操作和确认语义。

## 兼容性与失败处理

- 旧存储中 `editorial` 缺失的片段默认不显示在时间轴，等待分类阶段补齐；不在读取 UI 时临时猜测类别。
- 分类或整理写入若检测到来源/片段修订不匹配，应标记为过期并重新排队，不覆盖当前内容。
- 内容片段合并失败时保留所有原片段和选择状态，展示可理解错误；成功后清除选择并打开或定位到合并结果。
- 手动/自动标题或总结生成失败时，保留已有字段；只允许用户显式重试，不把失败字段伪装为成功。

## 验收标准

1. `isFinal == false` 的片段不出现在首页时间轴。
2. `isFinal == true` 但无文本、缺少分类、`lowInformation` 或 `pendingConfirmation` 的片段不出现在时间轴。
3. `isFinal == true`、有文本、分类为 `meaningful` 的片段即使标题和总结为空，也出现在时间轴；两字段随后补齐时更新原记录，不重复插入。
4. 分类只能从该片段自身转写证据得出；新转写或边界修订后旧分类不能被继续展示。
5. 详情页管理菜单不含相邻片段合并；详情页可单独生成或重生成当前片段标题和总结，且两者互不覆盖分类与边界状态。
6. 时间轴只能合并同一来源中完整片段序列连续的片段；隐藏的中间片段会使选择不合法。来源不同、片段与长录音混选、非相邻片段都不能提交。
7. 长录音文件合并的现有行为保持有效，不能与内容片段合并误路由。
8. 在模拟器完成构建、针对展示门槛/分类陈旧/多选约束/详情动作的自动化检查，并进行首页与片段详情的视觉验收。

## 实现范围

涉及内容分段生产分类与持久化、时间轴展示过滤、片段级标题/总结操作与状态、时间轴选择及两类合并路由、详情页管理菜单，以及相应的 repository/UI 测试。无需改 Watch 录音采集、原始音频编码、服务端 API 或产品原型。
