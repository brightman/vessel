# Final 内容片段的时间轴展示与合并设计

状态：用户已确认实施。

## 目标

让首页时间轴只展示已经完成边界确认、并被判定为有意义的内容片段。标题和总结不再阻塞片段展示，可以稍后生成。详情页不提供相邻片段合并入口，但保留对当前片段手动生成标题和总结的能力。时间轴的片段多选合并是唯一的片段合并入口。

## 展示规则

时间轴可见条件为：

```text
segment.isFinal == true
&& segment.hasText == true
&& segment.editorial?.classification == "meaningful"
```

标题和总结为空不影响可见性。生成完成后刷新同一条时间轴记录，不新建重复条目；生成中用轻量占位文案表示状态，不用占位标题或总结伪装成模型结果。

`isFinal` 表示片段覆盖范围具有足够的成功 ASR 与 VAD 证据、边界已关闭，而且 AI 话题统一阶段已完成。统一阶段对每个可评估边界作出切分、合并或保守保留边界（模型返回 `uncertain`）的终态决定；不存在可评估边界时，该阶段可以完成且保持候选边界。模型处理中、失败、取消、资源不可用或等待发送确认都不是终态。它不表示内容分类、标题或总结已经完成。缺少分类、分类为 `lowInformation` 或 `pendingConfirmation`、`isFinal == false`、无转写文本的片段都不出现在时间轴，但保留在完整录音/片段管理数据中，可从来源录音继续查看和处理。

### `isFinal` 的计算

- ASR 和 VAD 的成功覆盖先按时间范围求交集；只有两个阶段都成功覆盖的音频才进入 `successfulCoverage`。任一阶段未请求、失败、取消、资源缺失，或该区间尚未处理完成，都不能为它提供 final 证据。
- 自动分段只有在其全部音频范围被 `successfulCoverage` 覆盖、边界已关闭，且 AI 已完成该范围的话题统一后，才设置 `isFinal == true`。统一结果包括 `sameTopic` 合并、`newTopic` 切分、`uncertain` 保守保留边界；不存在可评估边界时可终态保留候选边界。话题模型处理中、失败、取消、资源不可用或等待发送确认都不是终态，相关范围继续保持非 final。话题切分/合并只能作用于尚未 final 的片段，所有产物保持非 final；这一轮所有可评估候选边界均得到终态决定后，再对覆盖完整且边界关闭的结果片段统一置为 final。
- 切分产生的尾段还要求来源录音已标记 `complete`；来源仍在录制或等待更多 Watch 分片时，开放尾段保持 `isFinal == false`。已由可靠边界封闭、完整覆盖且自动边界处理已结束的前段可以先 final，不必等待整条来源结束。
- 对尚未 final 的手动边界，重新协调只在其所有范围都被成功覆盖后保留边界；即使来源 complete，也必须等 AI 对相关话题边界作出终态决定后才能 final。时间轴手动合并只有在所有输入均 final 时才可执行；用户的明确合并选择本身就是该合并结果的话题终态决定，合并结果继续 final。
- 因此，`isFinal` 是按片段范围计算的边界/覆盖状态，不是“整条录音全部处理完”的同义词，也不是分类结果。分类必须等待 final 和有文本，标题/总结则不参与此计算。

### Final 边界锁定

片段一旦保存为 `isFinal == true`，它的音频范围和边界即锁定，状态单调保持 final。后续自动 reconcile、ASR/VAD 重试或重处理、自动静音分章、话题切分、自动同主题合并，都不得扩展、收缩、拆分或合并这个片段。自动边界算法只能处理尚未 final 的范围；新到达的尾部音频作为新范围处理，不能回头改写已锁定片段。

锁定边界不冻结片段内部的转写与语义整理：在原范围内获得新的成功转写时，可以更新该范围的转写，并据此重新分类或生成标题/总结；这些更新不得移动边界。追加在来源其他位置的新音频，不应使已锁定片段的分类缓存失效。片段自身范围或转写内容签名变化时，旧分类/标题/总结结果才需失效并重算。

final 片段唯一允许的边界变更是用户在时间轴明确选择同一来源中相邻片段并执行合并。合并结果覆盖所选片段原有范围，继续保持 `isFinal == true` 并成为新的锁定片段。详情页不提供 final 片段的手动拆分或合并入口；撤销仅用于恢复被用户明确执行的上一次编辑，不启动自动重分段。

### `isFinal == false` 的后续处理

`false` 的片段会保留在分段存储中，但按本设计不进入时间轴，也不启动该片段的分类、标题和总结生成。后续以下事件会重新协调分段并重算覆盖与边界：新音频分片或来源完成状态到达、ASR/VAD 窗口结果提交、AI 话题统一完成一个终态决定、用户重试失败任务、语音资源恢复后重试缺资源任务，或用户/系统触发重新处理。新证据覆盖完整、边界关闭且 AI 对话题统一完成终态处理后，片段可转为 final，再进入分类阶段。

`isFinal == false` 本身不会自动重试任务。仍有 pending 窗口时，现有处理队列会继续执行；失败或取消的窗口需要用户重试/重新处理，缺少系统语音资源的任务可在资源恢复后重试。若来源还未 complete 且片段是开放尾段，即使目前所有已到达音频都处理成功，也会等新分片或来源完成后再确认尾段边界。详情页应结合窗口状态和来源完成状态，显示“等待更多录音/处理”或“处理失败，可重试”等真实原因，不要只显示一个笼统的“仍在整理”。

## 处理顺序与数据流

1. 现有 ASR/VAD 处理只将双阶段成功覆盖作为确定边界的证据；待处理、失败或覆盖不足的范围继续保持非 final。
2. 自动静音分段生成候选边界后，AI 对每个可评估的尚未 final 相邻候选执行话题统一，给出切分、合并或保守保留边界（`uncertain`）的终态决定；若不存在可评估边界，话题阶段以保留候选边界结束。处理中、失败、取消、模型不可用或等待发送确认时不能 final。所有相关话题边界决定结束后，才将同时满足双阶段覆盖完整及边界关闭的结果片段置为 final。
3. 片段达到 final 后立即锁定；后续自动静音/话题边界建议不得改变它。`isFinal` 表示音频覆盖足够、边界已关闭且 AI 话题统一已完成；锁定片段自身的转写内容变化会使旧分类失效，来源其他范围变化不会。
4. 为每个 final、有文本的片段执行独立的内容分类。分类结果写入持久化 `editorial`，并带上模型/引擎版本、证据块 ID 和输入内容签名。只有目标片段仍存在、仍 final，且片段修订与输入内容签名仍匹配时才接受结果；来源其他范围的修订不能使它过期，避免无关新分片阻塞或重跑分类。
5. 分类完成且为 `meaningful` 时立即发布到时间轴，不等待标题或总结。
6. 标题与总结作为后续整理阶段异步生成。失败、取消、模型不可用或等待远程 AI 确认，不撤回已经通过分类的时间轴片段；按现有隐私确认规则执行远程请求。

分类使用既有类别：`meaningful`、`lowInformation`、`pendingConfirmation`。内容分类必须依据片段自身全文，不能从同日其他片段或整条录音推断。当前 V2 分类逻辑只在模拟器试验路径，生产时间轴尚未落库分类；接入生产流水线并持久化分类是实现的前置工作。

## 处理状态

片段详情的“处理状态”应区分并如实显示：转写/VAD 覆盖、边界状态、分类状态、标题状态、总结状态。至少需要覆盖等待、处理中、完成、失败/可重试、模型不可用、等待远程发送确认和内容已更新等状态。没有可靠进度时显示阶段和状态，不显示估算百分比。

来源级处理目前按来源串行；单个来源的标题与总结也按片段顺序整理。实现可先沿用现有调度器，但分类必须先于标题/总结发布，并与二者分开持久化，这样不会因后续生成慢而延迟时间轴展示。

## 手动生成

详情页提供针对当前片段的“生成/重新生成标题”和“生成/重新生成总结”操作，输入仅使用该片段的转写证据，沿用当前 AI 模型设置、输入签名及防陈旧写入规则。外部模型的发送确认必须明确绑定到这一个片段及当前字段，并预览该片段全文和实际发送的时间/地点上下文；不能用整份录音的预览代替片段级预览。单独重生成一个字段不得重置 `isFinal` 或分类，也不得创建新片段。失败或空结果不得清空已有标题/摘要。

当前实现只有来源级“整理主题与总结”按钮，它会遍历该来源的多个含文本片段；没有针对当前片段分别生成标题和总结的按钮。规格要求在详情页补上片段级操作。若来源级按钮继续保留，它仍作为来源级批量处理/重试入口，不替代片段级操作。

## 合并入口与语义

- 删除片段详情“管理片段”菜单中的“与相邻片段合并”。非 final 片段可按现有规则手动拆分；final 片段不提供手动拆分或合并入口。删除仍可用；撤销只撤销明确的手工编辑。
- 首页时间轴通过右划、选择、合并来合并内容片段。选中集合必须属于同一来源，并且在完整来源片段序列中连续；不能因为低信息片段被时间轴隐藏，就把其两侧片段误认为相邻。操作调用 `ContentSegmentRepository.merge(ids:expectedRevisions:)`，保留原始音频来源与范围，合并成功后以一个新片段替代被合并片段，再基于合并后的全文生成分类、标题和总结。
- 现有长录音条目的时间轴合并仍是另一种操作：它拼接独立录音文件并生成新的录音记录。多选时不可混合长录音和内容片段；两类记录继续使用各自的数据操作和确认语义。

## 兼容性与失败处理

- 旧存储中 `editorial` 缺失的片段默认不显示在时间轴，等待分类阶段补齐；不在读取 UI 时临时猜测类别。
- 旧版自动片段仅凭 ASR/VAD 覆盖写成 `isFinal == true`、且没有新版本 topic-pass 证据（`boundaryReady`）时，启动协调会降级为 provisional 并重跑话题统一；旧的手动 final 片段不降级。
- 分类或整理写入若检测到目标片段已删除、边界/片段修订变化或片段内输入内容签名变化，应标记为过期并重新排队，不覆盖当前内容；来源其他范围变化不使锁定片段的结果过期。
- 内容片段合并失败时保留所有原片段和选择状态，展示可理解错误；成功后清除选择并打开或定位到合并结果。
- 手动/自动标题或总结生成失败时，保留已有字段；只允许用户显式重试，不把失败字段伪装为成功。

## 验收标准

1. ASR/VAD 覆盖完整但 AI 话题统一尚未完成或失败时，片段保持 `isFinal == false`，且不出现在首页时间轴；可评估边界均有终态决定后，满足覆盖和边界条件的结果片段才变为 final。
2. `isFinal == true` 但无文本、缺少分类、`lowInformation` 或 `pendingConfirmation` 的片段不出现在时间轴。
3. `isFinal == true`、有文本、分类为 `meaningful` 的片段即使标题和总结为空，也出现在时间轴；两字段随后补齐时更新原记录，不重复插入。
4. 分类只能从该片段自身转写证据得出；片段内新转写后旧分类不能继续展示，来源其他范围新增音频不能使已锁定片段的分类失效。
5. 详情页管理菜单不含相邻片段合并；详情页可单独生成或重生成当前片段标题和总结，且两者互不覆盖分类与边界状态。
6. `isFinal == true` 后，追加音频、自动重试/重处理、静音分章或话题边界建议都不能改变其范围；详情页不允许拆分 final 片段。时间轴只能手工合并同一来源中完整片段序列连续的片段；隐藏的中间片段会使选择不合法。来源不同、片段与长录音混选、非相邻片段都不能提交，合并结果仍 final。
7. 长录音文件合并的现有行为保持有效，不能与内容片段合并误路由。
8. 在模拟器完成构建、针对展示门槛/分类陈旧/多选约束/详情动作的自动化检查，并进行首页与片段详情的视觉验收。

## 实现范围

涉及内容分段生产分类与持久化、final 边界锁定及仅对未 final 范围运行自动边界调整、时间轴展示过滤、片段级标题/总结操作与状态、时间轴选择及两类合并路由、详情页管理菜单，以及相应的 repository/UI 测试。无需改 Watch 录音采集、原始音频编码、服务端 API 或产品原型。
