# 首次使用引导原生实现

类型：实施计划；状态：实现与模拟器主要流程验证完成，真机待验收；更新：2026-11-02。
范围：iPhone；依据：[当前设计](../../../prototype/onboarding-design.md)，用户已批准开发。

1. 为首次安装、升级、未完成恢复、跳过和完成建立非敏感持久状态。资源就绪不持久化为永久事实；启动判定先于数据库初始化。
2. 复用现有转写下载、AI 配置及检索资源组件，接入四步首次引导。2026-11-02 后续用户要求移除设置回看入口；保留 Face ID、录音恢复和同步生命周期。
3. 按需申请健康、日历、地点与提醒事项访问；支持全不授权。使用已采集的模拟器截图提供 iPhone / Watch 使用说明。
4. 验证状态迁移及配置测试失效，构建并在独立模拟器验收首次安装、跳过、重启；保留已有模拟器数据验证升级。设置回看为此前验收事实，后续按用户要求移除。
5. 更新当前设计、总索引与同主题验证记录，分别记录自动测试、模拟器和真机结果。不提交、推送或发布。

注意：7／14 天留存仅沿用产品介绍，不引入自动删除。Apple Intelligence 以框架实际可用性为准；不把原型中的 27.3 文案当作系统能力门槛。API Key 仅进入已有 Keychain 配置路径。
