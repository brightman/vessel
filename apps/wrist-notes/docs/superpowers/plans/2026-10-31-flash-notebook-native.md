# 闪念整理与记事本原生实施计划

> 类型：实施计划 · 日期：2026-10-31 · 状态：原生代码已实现；核心与 8 项行动测试、编译、结果时间轴模拟器交互通过；真机验收待完成
> 依据：[已确认产品设计](../../../prototype/flash-assets-design.md)。用户已授权开发，在当前工作区保留全部既有改动；本任务不提交或发布。

**目标：** 闪念整理产生独立想法、账目和明确指令，设置末项进入记事本。

**架构：** 新增 FlashCapture 核心、SQLite repository、提取服务、运行时协调器及 SwiftUI views。复用 ActionRepository / ActionStore 的通知、系统日历、幂等标记与编辑流程。数据库以事务安装增量表，无删除或历史批量执行。

## 实施与验收

- [x] 核心及存储：FlashCapture.swift / FlashCaptureRepository.swift；先运行 FlashCaptureSmoke 验证缺失行为，再实现来源校验、明确指令校验、金额最小单位、按币种汇总、修订冲突、撤销和重启去重。
- [x] 自动提取：FlashCaptureService.swift / FlashCaptureModel.swift；转写完成后处理新闪念，历史默认跳过；尊重当前外部模型授权；提取失败可重试，完整批次只写入一次，不覆盖人工编辑。
- [x] 行动执行：事务同时写整理批次和行动，待执行动作恢复后复用稳定 ID；缺时间待补充，权限失败可重试；事件默认系统可写日历，待办本机、提醒本机通知，成功状态以实际结果为准。
- [x] 原生 UI：记事本在数据来源最后；我的想法／我的记账；想法正文与时间的紧凑列表；详情编辑、原话、撤销恢复；闪念整理／全文、我的记录快捷入口。
- [x] 来源时区：录制时写入可选时区元数据，历史未知时区不猜测行动时间；旧 JSON 继续可读。
- [x] 验证：核心 SQLite smoke、既有行动回归、iPhone/Watch 编译、结果时间轴模拟器导航与持久化。设备端 ASR、模型准确率和通知送达单独注明未验证状态。
- [x] 文档：更新产品设计原生状态、数据结构、AI prompt 目录、验证记录和总索引。

## 故障与恢复

整理完成标记与全部结果同事务提交。行动先落库为 pending 后调用系统；日历 ownership URL、通知 UUID 保证中断重试去重。已完成批次不因重转写重新生成；编辑用 revision 检查；撤销为持久化状态。删除录音不删除独立内容与来源快照。卸载旧版本回退不删除新表，旧版可忽略它们。

验证状态：SQLite/行动/录音草稿测试已通过；App/Watch 编译、模拟器安装启动已通过。早期 CUA 无法取得窗口；后续结果时间轴同步已恢复界面操作，验证编辑、完成、撤销、来源导航、搜索与重启保留。真实模型与真机行为未验收。详见[后续验证](../../../verification/flash-assets-prototype/README.md#timeline-native-20261031)。
