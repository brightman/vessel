# 地点与采集设备：原型评审

更新：2026-10-20。入口：`iphone-day.html#product`。

## 展示与交互

- 原型默认开启地点示例，方便评审；这不代表真实 App 自动获得定位权限。
- 每日「一天的节奏」增加绿色地点时间点，点击该行或「地点 3 处」打开当天地点列表，按时间倒序回看。
- 时间轴中的录音与图片显示采集设备；有地点时额外显示地点名和来源，例如「办公室 · 录音开始位置」或「办公室 · 照片原始位置」。
- 没有地点时省略整行，详情页同样不显示缺失状态或占位提示。
- 地点详情展示来源、采集时间、可用精度，并可返回关联录音或图片。照片示例分别展示拍摄和导入时间。
- 设置 → 数据来源 → 地点，可暂停或开启；暂停保留历史地点。新建模拟录音仅在开启时附上示例位置。
- 只有采集时间点，不绘制连续轨迹，不据此计算停留时长。

## 硬件信息

- 列表与详情区分 Apple Watch、iPhone、EurekaRing。示例中包含三种来源。
- 详情显示「录制设备」或「拍摄设备」；相册导入另列「导入方式」。
- 导入照片缺少设备信息时显示「设备未知」，不根据导入手机推断拍摄设备；浏览器相机选择的图片只标记为「本机相机」。
- 硬件来源与位置来源独立：EurekaRing 示例保留设备名，没有附带位置，因此不显示地点行。

## 实现与验证边界

仅修改 HTML 原型。地点、设备、精度和照片元数据均为示例；没有调用真实定位、读取 EXIF、操作蓝牙、访问地图服务或新增持久存储。实际选择的图片不会被附加虚构的地点。

保留现有视觉风格，使用主题变量适配深浅色；新增界面文案加入中英日词典。

JavaScript 语法检查与范围内 diff 检查通过。Chrome 已查看首页地点概览、当天地点列表、照片地点详情、返回照片、三类设备列表、照片拍摄设备/导入方式、EurekaRing 录音详情，并查看浅色首页与深色设置。最终「无地点不显示」按用户反馈调整；未执行原生 App 构建或真机测试。
