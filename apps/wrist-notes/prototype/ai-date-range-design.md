# Ask AI 自动查找记录 · 2026-10-23

本版取代此前手动选择时间范围的方案，仅更新产品原型。

## 交互

- 移除 AI Tab 的日期选择器，直接提问；轻量提示「按问题查找相关记录」。
- 问题指定时间时按指定时间查找；「最近」先查过去 7 天，示例记录不足时扩大查找，并在回答中说明。
- 无时间限制时跨时间查找；「之前有哪些想法」演示从全部获准记录筛选闪念。
- 「只看上周」「再往前找找」沿用上一个问题的主题。连续对话不再按范围拆开。
- 查询中展示查找状态。回答注明查找范围、实际引用日期及条数，并保留可打开的来源。
- 保留外部 AI 发送确认与免提示设置；预览仅包含本次引用的获准记录文字。
- 首页回看单日的日历不受影响；洞察 Tab 仍隐藏。

## 原型边界

固定演示日期 2026-10-19。时间识别、内容匹配及扩展检索均为规则演示，不连接真实 AI，不支持任意自然语言时间表达。所有记录与对话均为页面内状态。

## 验证

- node --check 通过。
- Node VM / DOM stub 检查通过：移除选择器；昨天、最近、上周、上个月、跨时间；追问沿用主题；连续历史及旧回答来源；数据权限；外部发送预览仅含引用。
